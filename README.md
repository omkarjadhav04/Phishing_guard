# PhishGuard

A browser-based learning project that checks website URLs and pasted email text for common phishing warning signs.

## Run locally

Open `index.html` in a web browser. No package installation or server is required.

## What it checks

- URLs for clues such as IP-address hosts, shortened links, encoded domain names, and suspicious account-related terms.
- Email text for urgent wording, requests for sensitive information, and suspicious links.

All checks run in your browser; submitted text is not sent to a server. This is a basic educational checker, not a security scanner. A low risk score does not prove that a link or message is safe.
